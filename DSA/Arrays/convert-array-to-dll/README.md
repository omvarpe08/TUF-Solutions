## 📝 Problem Statement

Given an array arr, convert it into a doubly linked list and return the head of the list.

### Example 1:

**Input:** arr = [1, 2, 3, 4]

**Output:** [1, 2, 3, 4]

### Example 2:

**Input:** arr = [7, 7]

**Output:** [7, 7]
